# Darukaa Earth Frontend

React + Vite + Tailwind + React Flow frontend.

## Run

```bash
npm install
npm run dev
```

Set `VITE_API_URL` when the FastAPI server is not at `http://localhost:8000`.

The UI exposes:
- Scientist conversational workspace
- Environmental profile editor
- Interactive causal reasoning graph
- Evidence/recommendation cards
- Session-based requests to POST `/chat`
